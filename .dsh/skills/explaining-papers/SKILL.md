# 带人吃透一篇论文

目标不是"摘要"，是四件可检验的事：**能 10 分钟讲清全貌、能指出它的数字哪里不可信、能说出它对你的项目具体改哪一行、能在被追问时不慌**。

## 三份产出（一份必做、一份每批必更、两份按需）

| 产出 | 什么时候做 | 格式 |
|---|---|---|
| **L1 笔记** `<slug>.md` | **每篇必做** | **固定 10 个角色**，见 `references/note-template.md`。⚠️ 节号会变（见下） |
| **INDEX.md 更新** | 每读完一批（≥1 篇） | L0 卡 + 横向矩阵 + 三种读法 + 落地清单，见 `references/index-template.md` |
| 自测题 `<slug>-自测.md` | 只给"最想彻底吃透"的那篇做 | 四级标尺 + 4 题组 + 杀手题 + 复述模板，见 `references/extra-deliverables.md` |
| 组会发言稿 `.docx` | 只给"要讲"的那篇做 | 6 段 / 4–5 页 / 5 分钟，见 `references/extra-deliverables.md` |

> 一份笔记读 30 分钟才算写完；**页数不是成果**，能答上"你最不信它哪个数"才是。

## 顺序不能颠倒

1. **先把 PDF 抽成带页码的文本**（`===== PAGE n =====` 标记），统计乱码页数。
   没有页码锚点就没有"可核对"这件事 —— 后面所有数字都要能回到某一页。
   用 `scripts/extract_pdf.py`（skill 相对路径）：

   ```powershell
   mini-agent\.venv\Scripts\python.exe .dsh\skills\explaining-papers\scripts\extract_pdf.py <x.pdf> --out .tmp/text/<名字>.txt
   ```

   它需要 `pypdf`。本项目的 venv **没有**装（pip 在沙箱里装不动），要加 `--lib .tmp/pdflib`。
   **两样都没有就停下来先解决依赖** —— 不要跳过这一步去做笔记：没有页码，后面所有数字都不可核对。
2. **边读边记关键数字**，每记一个就标 `[p.N]`。**不许先写笔记再回填页码**。
3. **数字交叉核对**：正文/摘要/表格/图注如果互相不一致，**单列清单**，别挑一个顺眼的。
4. **填 10 个角色**（`references/note-template.md` 有每节的判据与反例）。
5. **更新 INDEX**：L0 卡 6 行、矩阵加一列、三种读法、落地清单加行、诚实清单加条。
6. **`scripts/check_note.py` 过一遍**，再复制口径写到自测/发言稿。

## 哪几节是"读懂"的判据

⚠️ **按节名找，不按节号。** 这 10 个"角色"是固定的，但**节号会变**：批判在现有四篇里分别是
§7 / §6 / §6 / §12，术语表是 §10 / §9 / §9 / §15。因为有的论文会把「作者明说的局限」和「批判」
拆成两节，综述类还会多出好几节。**写"§6 批判"这种话的人，换个论文就会指错地方。**

| 角色（按名字找） | 判据（写不出来就是没读懂） |
|---|---|
| 五段速记 | 五段各一句，**局限那段必须是作者没直说、你读出来的** |
| 关键数字 | 每个数有页码；至少一张"消融/对照"表；能说出**最弱的那一个数** |
| 批判 | **至少一条作者自己没承认的**。只复述"作者明说的局限"等于没批判 |
| 与项目对接 | 具体到文件/函数（`evals/tasks.py::self_check`），不是"可以借鉴其思想" |
| 术语表 | 只收**读这篇之前不懂**的词，不收人人都懂的 |

## 三条不要做

- **不要写"论文说了什么"式复述**。读者要的是"所以呢、信不信、怎么用"。
- **不要引用没核对过页码的数字**。宁可写"待核"，也不要写一个看着对的值。
- **不要把"我的判断"混进证据**。判断单独成节（§6 批判 / INDEX 的「我的判断」「我更信哪部分」），并在诚实清单里声明"本文档未做实验"。

## 收尾自检

```powershell
mini-agent\.venv\Scripts\python.exe .dsh\skills\explaining-papers\scripts\check_note.py notes\papers\<slug>.md
mini-agent\.venv\Scripts\python.exe .dsh\skills\explaining-papers\scripts\check_note.py notes\papers\INDEX.md
```

它会查：顶部元信息表、五段速记五行、节的顺序、**页码锚点数**、表格/图引用、
批判节字数、对接节是否具体到代码、术语表行数、绝对路径。
不通过的项，多半是"你确实还没读到那一层"。

> 它按**内容**判别这份文件是笔记还是 INDEX（不按文件名 —— 文件名一改，判据就静默换一套）。
> 判不出类型时它会**拒绝判**，而不是拿错规则硬查。
