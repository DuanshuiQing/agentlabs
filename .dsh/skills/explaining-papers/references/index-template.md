# INDEX 模板（一批论文的入口页）

INDEX 不是目录，是**给"只有 10 分钟的人"看的**。它自己必须能单独成立：
只读 INDEX 也能说出四篇的关系、每篇值不值得读、以及"我该先改哪一行代码"。

一份 INDEX 的固定七件，顺序不能换：

---

## §0 关系图 + 一句话串起来

ASCII 框图：谁给地基、谁反驳谁、谁落地。框里放 2–3 个规模数字。
下面**一句话把全部论文串成一条因果链**（不是并列罗列）。

判据：删掉所有单篇笔记，只看这张图 + 这句话，能讲 2 分钟。

---

## §1 L0 速览卡（每篇一张，6 行固定）

| 一句话结论 | |
| --- | --- |
| 解决什么真问题 | |
| 方法一句话 | |
| 最硬的证据 | 带数字，且是最反直觉的那个 |
| 我的判断 | **哪部分值得照搬 + 弱在哪**，一句 |
| 值不值得细读 | ★评级 + 读哪几节 + 哪几节可跳 |

每张 ≤120 字。**"我的判断"和"值不值得细读"是这份卡存在的理由** —— 没有它们就只是摘要。

---

## §2 横向对比矩阵（维度固定，行不能少）

| 维度 | 论文A | 论文B | … |
|---|---|---|---|
| 抽象层次 | | | |
| 论文类型 | 注明是否同行评审 | | |
| 核心贡献 | | | |
| 实验对象 | 模型/数据集/规模 | | |
| 开源 / 可复现 | | | |
| 攻击面 / 适用范围 | | | |
| 对工程的直接可用度 | 高 / 中 / 低 + 理由 | | |
| **我更信哪部分** | 强在哪、弱在哪 | | |
| **主要遗留风险** | | | |

最后两行是这张表的全部价值 —— 它们是**判断**，不是事实。

---

## §3 三种读法（按你手上时间选）

- **10 分钟**：§0 图 + §1 四张卡 + §2 最后两行 → 记住三句话（写出来是哪三句）
- **1 小时**：给一张表（顺序 / 篇目 / 读什么节 / 用时）
- **半天**：先按 1 小时读，再读每篇的对接与批判节，最后从 §4 挑 3 条动手

判据：三种读法都能在**不打开单篇笔记**的情况下执行。

---

## §4 与项目的落地清单

| 优先级 | 改动 | 落在哪（文件/函数） | 依据（哪篇哪节） |
|---|---|---|---|
| P0 | | | |

P0 = 不做会持续吃亏；P3 = 将来再说。**每条都要有"依据"**，否则就是个人偏好。

## §5 跨篇术语表

| 术语 | 通用解释 | 谁在用 |
|---|---|---|

同一概念被多篇用不同叫法时，在这一行里注明。

---

## §6 已知缺陷与"未核实"清单

这一节**必须存在**，且必须包含：

1. 页码口径（PDF 物理页 vs 印刷页）；
2. 凡是**你推定的**（比如"这个 caption 没写用的哪个攻击，我据正文推的"）；
3. 原文自身不一致的处数 + 指到单篇的清单；
4. **自己猜错过并更正过的地方** —— 写出来，这是可信度的一部分；
5. 一句话声明"**本文档未做任何实验**，所有数字来自原文；判断是判断，不是证据"。

---

## §7 复现抽取管线 + 更新记录

- 抽取命令（PDF → 带 `===== PAGE n =====` 的纯文本），以及每篇的页数 / 词数 / 乱码页数表。
- 更新记录：日期 + 做了什么 + 新增了哪份产出。
