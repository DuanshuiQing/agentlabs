# L1 笔记模板（固定 10 节）

一份 L1 笔记 200–300 行。**节号不能改**，因为 INDEX、自测、发言稿都按这个顺序引。
每节下面写的是「写什么 / 多长 / 判据 / 反例」。

---

## 顶部元信息表（正文之前）

| 项 | 内容 |
| --- | --- |
| 作者 / 单位 | 全名 + 上标单位；**别把作者单位猜成"国内某团队"**（踩过） |
| 出处 | 会议或预印本 + arXiv/ePrint 编号 + 日期 + **页数** |
| 资源 | 代码 / 榜单 / License / DOI 链接 |
| 原文 | PDF 路径 + 抽取文本路径 |
| 阅读范围 | 全文 / §1–§5 + 附录哪几张表（**没读的要说没读**） |

---

## §0 五段速记（组会 1 分钟版）

表格五行，每行一句话，**不超过 80 字**：

| 段 | 写什么 |
|---|---|
| 问题 | 它要解决的真问题，不是"研究 X" |
| 方法 | 一句话 + 关键规模数字（4 套件 / 629 用例 / 13 数据集） |
| 实验 | 最硬的那个数 + 反直觉的那个数 |
| 局限 | **作者没直说的那一条**优先；作者明说的排后面 |
| 可复现第一步 | 一条今天就能跑的命令级动作，不是"通读全文" |

判据：五段连起来能当电梯稿念完，且不含"本文提出了一个框架"这类空话。

---

## §1 一句话结论

**一句**，长句可以，但要含三样：把什么从 A 升级成 B + 一个数字 + 一个反转。
反例："本文提出了一套评测环境并在多个模型上做了实验。"（等于没说）
正例见 `notes/papers/agentdojo.md` §1。

---

## §2 问题与动机

编号列表 **3–5 条**，每条一个 `[p.N]`。要求：

- 每条都写"现有做法为什么不够"，而不是"这个问题很重要"。
- 至少一条是**方法论的缺口**（比如"用 LLM 当裁判会被注入一起骗"），不只是"缺数据"。
- 引用原文时给英文短句，别翻译后再放页码。

---

## §3 方法骨架

拆成 3.1 / 3.2 / 3.3…，每个子节对应一个"你能画出来的东西"：

- **3.1 构成**：把表 1 / 图 2 抄成 markdown 表（套件数、工具数、任务数…），标 `(Table 1, p.6)`。
- **3.2 机制**：它是怎么把 A 变成 B 的？给流程（编号步骤或 ASCII 图）。
- **3.3 假设与威胁模型**：**这节最容易被跳过，也最值钱** —— 它决定了结论的适用范围。
- **3.4 判定口径**：什么算成功、什么算失败、谁在打分（人类 / 断言 / LLM 裁判）。

判据：合上笔记，能用三句话把方法讲给同组的人，且第三句是"它的判定口径是…"。

---

## §4 实验设计与关键数字

两到三张表，全部**从论文表格抄**，不要抄摘要里的数：

1. **主结果表**（`Table 3, p.20` 这种）
2. **消融 / 对照组表**（证明"哪个部件在起作用"）
3. 有的话：**敏感性表**（换措辞/换模型/换预算后的变化量）

每张表下面写一行"**这张表最弱的地方**"。

---

## §5 结论与作者主张

作者自己的结论（原文一句话 + 页码）→ 哪些站得住 → 哪些是**作者的措辞便宜**（比如"perfect security"其实只是"静态攻击集上 ASR=0"）。

---

## §6 批判与未解问题

**≥150 字，且必须含至少一条作者没有自己承认的问题。**
只复述 §6 的"作者明说的局限"不算批判 —— 那是转述。

好用的四个角度：
- **证据强度**：这个数的置信区间 / 样本量 / 是否自控实验？
- **可复现性**：要真仪器吗？人工基线可复现吗？代码真能跑吗？
- **口径**：accuracy 是"合规判定"还是"攻击成功"？（这类偷换很常见）
- **威胁模型**：它的假设在真实部署里成立吗？

如果发现**正文与表格数字不一致**，单列子节「数字不一致清单」，并写明"引用时以表格为准"。

---

## §7 与我的项目对接（具体到代码）

表格或编号列表，**每条都要落到文件/函数**：

| 改动 | 落在哪 | 依据 |
|---|---|---|
| dispatch 输出统一打"不可信"标记 | `tools.py::dispatch` | 论文 §4.2 delimiting 双收益 |

判据：出现 `.py` / `::` / 具体目录名。写"可以借鉴其思想"的，删掉重写。

---

## §8 关键原文句

3–6 句**英文原句** + `[p.N]`。挑标准：这句话要么定义了概念，要么是一句能背出来唬住人的结论。
不要放"我们提出了一个框架"这种。
